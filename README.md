# Minesweeper

A classic Minesweeper game built with React and Vite.

## How to Play

-   Select a difficulty level to start the game.
-   Click on a cell to reveal it.
-   If you reveal a mine, the game is over.
-   If you reveal a number, it indicates the number of mines in the adjacent cells.
-   Right-click on a cell to place a flag where you suspect a mine is located.
-   The objective is to reveal all cells that do not contain mines.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

-   Node.js and npm (or yarn/pnpm).

### Installation

1.  Clone the repo.
2.  Install NPM packages:
    ```sh
    npm install
    ```

### Running the Application

1.  Run the development server:
    ```sh
    npm run dev
    ```
2.  Open your browser and navigate to `http://localhost:5173` (or the address shown in your terminal).
